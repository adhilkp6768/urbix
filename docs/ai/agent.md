# Investigation graph

Deterministic Python:

- Dataset retrieval, aggregation, baselines, metrics, spatial joins, and report assembly.
- Tool execution. The model never receives a SQL string to run.
- Claim labels: observed, statistical, limitation, unavailable, documented, rejected.
- The number check that drops a summary containing a figure absent from the evidence.

A language model is optional and only chooses tool names from the registry. If `OPENAI_API_KEY` is empty, keyword rules choose the same tools. LangGraph wires plan → execute → compose when the package imports. The same three functions run directly if it does not.

Retrieval searches methodology markdown under `docs/` by token overlap. That is lexical retrieval. pgvector is attempted on PostgreSQL and skipped when the extension is missing. Embeddings are not fabricated.

Reports copy KPI statements. They do not ask a model to invent a city statistic.
